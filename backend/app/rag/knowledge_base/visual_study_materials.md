title: Materiais visuais para estudo guiado
source_type: guideline
topic: visual learning, concept maps, examples, formulas
---

Conteúdos densos ficam mais claros quando são convertidos em representações visuais simples.

Estratégias úteis:

- criar mapa conceitual quando houver relação entre ideias;
- usar caixas curtas para conceitos principais;
- usar setas para mostrar sequência, causa ou dependência;
- transformar processos em passo a passo;
- explicar fórmulas por partes;
- dizer para que cada fórmula serve;
- incluir exemplos práticos e próximos do conteúdo;
- separar glossário de explicação.

O material visual deve evitar poluição. Poucos elementos bem organizados ajudam mais do que muitos destaques.
