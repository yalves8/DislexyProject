title: Adaptação de fórmulas e conteúdo matemático para dislexia
source_type: guideline

Para adaptar conteúdo matemático a pessoas com dislexia:

- apresentar a fórmula isolada, em destaque, antes de qualquer explicação;
- nomear cada variável ou símbolo em linguagem simples logo abaixo da fórmula (ex: "v = velocidade do objeto", "t = tempo em segundos");
- nunca misturar a fórmula com texto corrido no mesmo parágrafo;
- mostrar um exemplo numérico concreto imediatamente após a definição;
- quebrar qualquer cálculo em etapas numeradas e curtas;
- indicar explicitamente qual variável está sendo isolada em cada etapa;
- usar palavras de transição entre etapas: "primeiro", "agora substituímos", "o resultado é";
- quando houver mais de uma fórmula, introduzir uma por vez;
- comparar a fórmula com uma situação do dia a dia sempre que possível;
- ao final, criar uma checagem: "o que cada letra representa?".

Erros comuns a evitar:

- usar letras gregas sem explicar o que significam;
- apresentar a derivação completa antes de mostrar o resultado final;
- misturar unidades de medida sem destacá-las.

A progressão recomendada é: enunciado simples → fórmula destacada → significado de cada parte → exemplo resolvido passo a passo → resumo do que foi aprendido.
