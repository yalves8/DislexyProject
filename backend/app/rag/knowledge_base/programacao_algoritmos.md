title: Adaptação de conteúdo de programação e algoritmos para dislexia
source_type: guideline

---

Textos de programação exigem que o leitor processe lógica abstrata, sintaxe não-natural e múltiplos conceitos encadeados — uma carga cognitiva alta para pessoas com dislexia.

Diretrizes para adaptação:

- antes de mostrar qualquer código, descrever em linguagem simples o que ele faz ("este trecho verifica se um número é maior que zero");
- quebrar algoritmos em passos numerados com verbos de ação: "1. Receba o número. 2. Verifique se é maior que zero. 3. Mostre o resultado.";
- explicar cada variável com nome e função: "a variável 'contador' guarda quantas vezes o loop já rodou";
- ao introduzir um conceito novo (loop, função, lista), usar uma analogia do cotidiano antes da definição técnica;
  - ex: "uma função é como uma receita — você chama pelo nome e ela executa os passos";
  - ex: "um loop é como repetir uma tarefa até terminar a lista de afazeres";
- apresentar pseudocódigo ou descrição em português antes do código real;
- comentar o código linha a linha quando for necessário incluí-lo;
- nunca apresentar um bloco de código com mais de 10 linhas sem interromper com uma explicação;
- para estruturas de dados (listas, dicionários, árvores), usar uma representação visual descrita em texto antes do exemplo em código;
- destacar erros comuns e o que eles significam em linguagem simples;
- terminar com: "o que este código recebe → o que ele faz → o que ele retorna".

Para algoritmos de busca e ordenação: descrever o passo a passo com um exemplo pequeno e concreto antes de generalizar.
